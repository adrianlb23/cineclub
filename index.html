Sobre el proyecto

Este proyecto universitario es el resultado de la colaboración entre dos estudiantes, con el objetivo de crear una aplicación web que refleje no solo nuestros conocimientos, sino también nuestra capacidad para aplicar soluciones prácticas en un entorno real. La plataforma ha sido desarrollada utilizando tecnologías clave como HTML, CSS, y JavaScript, buscando un diseño de interfaz atractivo. Este proyecto no solo representa una parte fundamental de nuestra formación académica, permitiéndonos poner el práctica nuestro aprendizaje, sino que también tiene como finalidad servir como una pieza clave en nuestros portafolios profesionales de cara al futuro, destacando nuestras habilidades técnicas y nuestro enfoque en la creación de aplicaciones eficientes y funcionales.
